Purpose
Kick VOD chat requests five-second history pages. Its original timer advances
on attempted requests without completed-page headroom. This extension replaces
only the recognized replay query/timer segment to keep about 15 seconds of
completed history ahead of playback. Native rendering is preserved.

Code review
Runtime files in extension/ are readable JavaScript, without dependencies,
bundling, transpilation, obfuscation, eval, Function constructors, remote
imports or remote adapter updates. Minified matching anchors describe public
website segments; they are not obfuscated extension logic. The matcher allows
bijective identifier renames and numeric module-import IDs while preserving
properties, literals, operators, order and adjacency. Quoted/commented or
ambiguous matches cannot supply executable anchors.
Firefox webRequest.filterResponseData transforms the recognized segment during
onBeforeRequest. Downloaded Kick code never executes in the privileged
extension context. The replacement is local packaged code executed by Kick's
page. CSP/security headers and third-party library code are unchanged.

Permissions and data
Only kick.com and assets.kick.com are allowed. webRequest/webRequestBlocking
filter script responses; storage saves the enable preference. Invalid UTF-8,
unknown and ambiguous code pass through unchanged. Bounded filters close or
disconnect on timeout/error. Live chat keeps its native behavior.
No analytics, data collection or extension-originated network requests. Kick's
page continues its normal channel/time history requests. Diagnostics are local
numbers, excluding chat text and usernames.

Testing and reproduction
Firefox desktop 142+. Open a public Kick VOD, play several minutes, inspect
popup buffer diagnostics, pause/resume, seek backward 5-10 seconds and forward,
then test 2x and a cached reload. Toggle off/on and reload to apply changes.
Current public example:
https://kick.com/maddyson/videos/01a10d48-8960-7f24-aade-189d84b44b61
No Kick login required. Unsupported site logic must remain untouched.
Run npm ci, npm test, npm run lint, npm run build. Only extension/ is packaged,
without compiling or minifying. Source archive builds reproduce the XPI hash.
19 tests pass; lint has zero errors/warnings. Native Firefox 156.0.1 playback,
emotes, seeks and final-package cached reload were checked. Detailed evidence
and limitations: submission/validation.md. Raw browser/session data is excluded.
Public source: https://github.com/szanko02/kick-vod-chat-fix
