# Kick VOD Chat Fix

Расширение для настольного Firefox 142+. Поддерживает запас уже загруженного
чата записи Kick примерно на 15 секунд вперёд и сохраняет родной вывод сообщений.
Вместо продвижения таймера после попытки запроса учитывает завершённые страницы.

## Использование

После установки откройте запись Kick и перезагрузите страницу. Значок и окно
расширения показывают применение исправления и состояние буфера раздельно.
Переключение включения применяется после перезагрузки записи.

Диагностика остаётся в браузере и содержит числовые показатели, без текста
сообщений и имён пользователей. Сохранён только переключатель включения.
Историю по-прежнему получает сама страница Kick с серверов Kick.

## Сборка

Нужен Node.js с npm. Выполните:

```text
npm ci
npm test
npm run lint
npm run build
```

Пакет содержит только файлы `extension/`: код читаемый, без сборки в единый
скрипт и без минификации. Исследовательские загрузки и `legacy/` не включаются.
Временная установка из `about:debugging` нужна только для разработки.
Для обычного Firefox нужен подписанный Mozilla пакет или установка из AMO.

## Ограничения

Распознаются проверенные варианты компонента Kick. При изменении его структуры
исходный скрипт остаётся без изменений; потребуется новая версия расширения.
Иконка применения исправления сама по себе не доказывает плавность чата.
Расширение не восстанавливает удалённые VOD и не гарантирует работу сервера Kick.
Число страниц истории ограничено: просмотр более раннего чата требует перемотки.

Материалы для магазина находятся в `submission/`; результаты проверок —
в `submission/validation.md`. Одобрение решает Mozilla.
